# Platform Skill

Use this skill when you need cloud-specific behavior guidance.

- Prefer the `skill` tool to load other skill instructions on demand.
- System skills are loaded internally; users only see skill invocations in the status bar.
- User-installed skills belong to the session owner and override system skills with the same name.
